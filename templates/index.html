About

This tool is designed to help users easily gather detention and demurrage tariff information from the Hapag-Lloyd shipping line. It performs the following tasks:

  1. Scrapes the Hapag-Lloyd website to identify available regions and countries
  2. Downloads tariff PDF documents for each country
  3. Processes the PDFs to extract structured tariff data
  4. Stores the information in a database for easy access and analysis
  5. Provides a manual PDF upload feature when web scraping is blocked or for offline documents
  6. Generates realistic shipping industry test data when live data cannot be accessed
Extracted Information
  • Country and region information
  • Port names within each country
  • Equipment types (20" Dry, 40" High Cube, etc.)
  • Currency used for tariffs
  • Free days allowed
  • Rate buckets with day ranges and amounts
  • Validity periods for the tariffs
